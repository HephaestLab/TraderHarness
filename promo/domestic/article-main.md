LLM 炒股 Agent 今年彻底火了。让大模型读公告、看 K 线、自己下单，回测收益动辄年化翻倍——几乎每个这类项目的 README 里，都躺着一张漂亮的净值曲线。

但很少有人追问一句：**这条曲线，有多少是模型"交易"出来的，又有多少是它"背"出来的？**

## 一个被普遍无视的问题：模型可能认得考题

现在主流的 LLM trading 项目（包括那个 6 万多 star 的 AI 对冲基金），回测方式大同小异：把历史行情和新闻丢给模型，告诉它"今天是 2024 年 3 月 14 日，贵州茅台现价 1700 元"，然后看它的买卖决策。

问题在于：**通用大模型很可能"认识"这段历史。**

茅台 2024 年的走势、2025 年那几波暴跌、每轮牛熊的时间点——这些全都躺在模型的预训练语料里。当你把真实日期和真实公司名喂给它，它根本不需要分析，只需要"回忆"。这样的回测，本质是开卷考试，而且答案就印在考卷上。

更麻烦的是另外两件事：

- **时点泄漏**：Agent 查"最新公告"时，拿到的可能是当时还没发布的公告；看到的新闻是事后才被报道的。未来函数以最隐蔽的方式混进决策。
- **口径混乱**：成交价用开盘价还是收盘价？复权还是不复权？每个项目各搞一套，跑出来的收益根本无法横向比较。

所以现在的局面是：Agent 交易的研究越来越多，但**没有一个规范化的"考场"**——你分不清一个 Agent 是真有 Alpha，还是只是记性好。

## 我们做了一个"防作弊考场"：TraderHarness

TraderHarness 是一个面向 LLM 交易 Agent 的抗污染回测环境。它解决的核心问题就一个：**让模型在完全不知道"自己身处哪段历史"的前提下做交易，并且整个过程可复现、可审计。**

几个关键设计：

**1. 双重遮罩：日期和实体全部匿名化**

Agent 看到的不是"2024-03-14"，而是"D-1"；不是"贵州茅台"，而是一个确定性映射出来的伪代码。映射种子固定，同一次运行内自洽，跨运行不可猜测。模型无法触发任何关于真实历史走势的记忆。

**2. 严格的时点安全**

所有数据出口（日线、5 分钟线、公告、新闻、基本面）都强制按当前模拟时点过滤，盘前看不到盘中的数据，盘中看不到收盘后的公告。没有未来函数。

**3. 唯一受控的下单路径 + 确定性引擎**

所有成交必须经过同一个撮合入口，按不复权的历史真实价格结算；市场数据全部预载在内存，回测过程零 I/O——同样的输入必然得到同样的结果。

**4. 指纹回放**

每一次 LLM 调用的完整请求都会记录指纹。生成的回放盒带可以在没有 API Key 的情况下逐位复现整个回测，分享前还有泄漏审计扫描。别人可以精确复核你的每一次决策上下文——这在 Agent 评测里是我们目前唯一见到的做法。

## 实战检验：让 4 个主流模型去跌最狠的一个月

光说机制不够，我们直接做了组实验。

2026 年 6 月 20 日 – 7 月 20 日，A 股急速回撤，沪深 300 区间收益 **-9.12%**——标准的魔鬼行情。我们在这个窗口用同一张"趋势波段" Agent 卡（双重遮罩、种子 42、初始资金 100 万），让 4 个主流模型各自独立跑完 21 个交易日：

| 模型 | 区间收益 | 相对沪深300 | 夏普比率 | 最大回撤 | 交易笔数 | 胜率 |
|---|---|---|---|---|---|---|
| Claude Opus 4.8 | **+1.45%** | +10.57 | 2.61 | 0.76% | 6 | 66.7% |
| Kimi K2.6 | +0.34% | +9.46 | 0.69 | 0.37% | 2 | 100% |
| Qwen3.7-Max | -1.64% | +7.48 | -3.77 | 1.64% | 12 | 0% |
| DeepSeek V4-Pro | -2.69% | +6.43 | -6.57 | 2.69% | 10 | 20.0% |

四个模型全部大幅跑赢指数。但更有意思的是**行为差异**：Kimi 全月只出手 2 次，稳到近乎懒惰；Qwen 出手 12 次却无一盈利，越努力越亏钱；Claude 6 笔交易、回撤不到 1%，展现出明显的纪律性。

同样的市场、同样的工具、同样的提示词契约——模型的"性格"一目了然。这就是一个规范化考场该回答的问题。

（要说明：这是小样本、单 Agent 风格的冒烟测试，不构成模型排名。每次调用的完整轨迹都可以回放复核。）

## 附带产物：它还是一个训练数据合成器

因为每一次模型调用都被全保真记录（完整消息、工具 schema、推理内容、每次工具调用的参数），每次回测同时就是一次数据生产：

```bash
traderharness audit result.json replay.jsonl      # 泄漏审计
traderharness export sft result.json --output training.jsonl   # 轨迹导出
```

导出的是 OpenAI 风格的轨迹 JSONL，由遮罩和泄漏检查把关——可以直接用于 SFT/RL 的专项训练数据。我们已经把一套 5 年 A 股全市场数据（日线 + 5 分钟线 + 公告 + 新闻 + 基本面 + 估值 + 分红 + 沪深300）打包发在 Hugging Face 上。

## 60 秒上手

```bash
pip install "traderharness[llm,data,ui]"
traderharness data download --full
traderharness demo        # 无需 API Key，流式回放一段遮罩轨迹
```

本地研究控制台（FastAPI + React）里有个像素风办公室：每个 Agent 是一个小人，盘前查资料、盘中下单、尾盘复盘全程直播——回测第一次变成可以围观的现场。

## 写在最后

LLM 进入交易这个场景，现在缺的不是更多"会炒股的 Agent"，而是**一套能判断 Agent 到底行不行**的基础设施。没有规范考场，所有收益曲线都只是市场营销。
