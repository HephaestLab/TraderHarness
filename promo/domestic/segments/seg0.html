LLM 炒股 Agent 今年彻底火了。让大模型读公告、看 K 线、自己下单，回测收益动辄年化翻倍——几乎每个这类项目的 README 里，都躺着一张漂亮的净值曲线。

但很少有人追问一句：这条曲线，有多少是模型"交易"出来的，又有多少是它"背"出来的？

一个被普遍无视的问题：模型可能认得考题

现在主流的 LLM trading 项目（包括那个 6 万多 star 的 AI 对冲基金），回测方式大同小异：把历史行情和新闻丢给模型，告诉它"今天是 2024 年 3 月 14 日，贵州茅台现价 1700 元"，然后看它的买卖决策。

问题在于：通用大模型很可能"认识"这段历史。

茅台 2024 年的走势、2025 年那几波暴跌、每轮牛熊的时间点——这些全都躺在模型的预训练语料里。当你把真实日期和真实公司名喂给它，它根本不需要分析，只需要"回忆"。这样的回测，本质是开卷考试，而且答案就印在考卷上。

更麻烦的是另外两件事：

  • 时点泄漏：Agent 查"最新公告"时，拿到的可能是当时还没发布的公告；看到的新闻是事后才被报道的。未来函数以最隐蔽的方式混进决策。
  • 口径混乱：成交价用开盘价还是收盘价？复权还是不复权？每个项目各搞一套，跑出来的收益根本无法横向比较。

所以现在的局面是：Agent 交易的研究越来越多，但没有一个规范化的"考场"——你分不清一个 Agent 是真有 Alpha，还是只是记性好。

我们做了一个"防作弊考场"：TraderHarness

TraderHarness 是一个面向 LLM 交易 Agent 的抗污染回测环境。它解决的核心问题就一个：让模型在完全不知道"自己身处哪段历史"的前提下做交易，并且整个过程可复现、可审计。

几个关键设计：

1. 双重遮罩：日期和实体全部匿名化

Agent 看到的不是"2024-03-14"，而是"D-1"；不是"贵州茅台"，而是一个确定性映射出来的伪代码。映射种子固定，同一次运行内自洽，跨运行不可猜测。模型无法触发任何关于真实历史走势的记忆。

2. 严格的时点安全

所有数据出口（日线、5 分钟线、公告、新闻、基本面）都强制按当前模拟时点过滤，盘前看不到盘中的数据，盘中看不到收盘后的公告。没有未来函数。

3. 唯一受控的下单路径 + 确定性引擎

所有成交必须经过同一个撮合入口，按不复权的历史真实价格结算；市场数据全部预载在内存，回测过程零 I/O——同样的输入必然得到同样的结果。

4. 指纹回放

每一次 LLM 调用的完整请求都会记录指纹。生成的回放盒带可以在没有 API Key 的情况下逐位复现整个回测，分享前还有泄漏审计扫描。别人可以精确复核你的每一次决策上下文——这在 Agent 评测里是我们目前唯一见到的做法。
