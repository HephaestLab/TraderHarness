在聚宽待久了，"未来函数"四个字基本刻进了肌肉记忆：用了未来数据的回测，收益曲线再漂亮也是自欺欺人。

最近 LLM 交易 Agent 很火，我也跟风研究了一阵。看着 GitHub 上那些项目 README 里的年化收益，一开始挺兴奋，后来越想越不对劲——**LLM 回测里的"未来函数"，比传统策略隐蔽得多**。

## 模型可能早就"背过答案"

传统策略的未来函数好查：代码里引了明天的收盘价，review 一遍逻辑总能发现。但 LLM 不一样。

你拿 2024 年的行情回测，让 GPT / Claude / Qwen 这些模型"逐日决策"。问题是——**2024 年的新闻、公告、甚至股价走势，大概率就在人家的训练语料里**。你问它"2024 年 3 月 15 日该买还是该卖"，它根本不需要分析，它"记得"后来涨了。

这不是策略在预测，是模型在开卷考试。

我观察下来，这个赛道目前大概三类项目：

- **论文复现类**：流程完整，但大多默认"模型不知道未来"，极少做数据污染防护；
- **实盘工具类**：接交易所 API 下单是强项，回测基本是赠品，更别提防污染；
- **传统回测框架**：聚宽、vnpy、backtrader 这些很成熟，但都不是为"LLM 作为决策主体"设计的——模型会到处搜数据、会记住历史，传统框架的防泄漏假设管不住它。

## 刷到一个较真这个点的项目

前阵子在 GitHub 刷到 **TraderHarness**，一个专门给 LLM Trading Agent 做回测和评测的开源框架。吸引我的就是它对"开卷考试"这件事的处理，研究了一阵，觉得思路挺扎实：

**1. 污染免疫的数据通道。** 所有数据（日线、5 分钟线、新闻、公告、基本面）在进 Agent 视野之前，先过一道"日期 + 实体"双重遮罩——未来的数据在 Agent 的世界里物理上不存在，连"贵州茅台"这类实体名都会被替换成代号。模型就算在训练语料里背过这段历史，也对不上号。

**2. 事件按披露时间落地。** 公告、新闻按真实披露时点进入事件流，而不是按交易日粗暴对齐。财报有没有提前"漏"进前一天，框架层面直接管死。

**3. 确定性回放。** 同一份可见数据 + 同一个动作序列，重放结果完全一致，连订单号都一样。做 Agent 实验的应该知道这有多重要——不然你根本分不清两次跑的差异是模型能力还是环境噪声。

**4. 不只看收益，还看行为。** 它有组行为画像指标：换手、持仓集中度、回撤纪律这些。收益可能是运气，行为模式才反映"决策质量"。

## README 里的实测数据，比同类项目克制

它 README 里放了组冒烟基准，数字我直接搬过来：2026 年 6 月 20 日到 7 月 20 日那段急速回撤（沪深 300 区间 -9.12%），同一张"趋势波段" Agent 卡、双重遮罩、种子 42、初始资金 100 万，4 个主流模型各自独立跑 21 个交易日：

| 模型 | 区间收益 | 相对沪深 300 | 夏普比率 | 最大回撤 | 交易笔数 | 胜率 |
|---|---|---|---|---|---|---|
| Claude Opus 4.8 | **+1.45%** | +10.57 | 2.61 | 0.76% | 6 | 66.7% |
| Kimi K2.6 | +0.34% | +9.46 | 0.69 | 0.37% | 2 | 100% |
| Qwen3.7-Max | -1.64% | +7.48 | -3.77 | 1.64% | 12 | 0% |
| DeepSeek V4-Pro | -2.69% | +6.43 | -6.57 | 2.69% | 10 | 20.0% |

这组数字比那些"年化翻倍"的 README 克制多了：收益最高的也就 +1.45%，但四个模型全部大幅跑赢同期指数。更有意思的是风格差异——Kimi 全月只出手 2 次、胜率 100%；Qwen 出手 12 次却无一盈利。**同样的市场、同样的工具、同样的提示词，模型性格一目了然。** 这才是规范化回测该回答的问题。

另外它还有个**轨迹导出**功能：Agent 每一天看到什么数据、怎么推理、怎么下单，全程录成轨迹，可以导出做 SFT / RL 训练数据。如果你在做交易方向的模型训练，这个功能可能比回测本身还值钱。

添头是个"像素办公室"：Agent 的交易过程变成办公室里的小人走来走去，盯回测的时候看 Agent 摸鱼，还挺解压。

## 几个劝退点

- 它是**研究框架**，不是实盘系统，想直接接券商下单的别想了；
- A 股全市场数据需要自己准备（公开数据源，文档里有说明），上手有一点门槛；
- 文档以英文为主，对国内用户不算友好（好在 README 是中文的）；
- 烧 API 额度。一个月的窗口、四个模型跑下来，成本得小几百块，README 里有详细成本测算，这点挺实在。
