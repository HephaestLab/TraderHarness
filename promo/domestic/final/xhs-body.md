LLM 炒股 Agent 今年彻底火了，不是没人做回测——几乎每个项目的 README 里都躺着一条漂亮的净值曲线。但几乎没有一个回测经得起追问：这条曲线有多少是模型交易出来的，又有多少是它背出来的？能回答这个问题的规范化回测框架，一直是空白。

你告诉模型“今天是 2024 年 3 月 14 日，茅台现价 1700 元”，这段行情大概率就在它的预训练语料里。它不需要分析，只需要回忆。除此之外还有两个更隐蔽的问题：时点泄漏（查“最新公告”拿到当时还没发布的信息），以及成交口径混乱导致结果无法横向比较。

我们为此做了个开源项目 TraderHarness，一个抗污染的 LLM 交易 Agent 回测环境：

- 双重遮罩：日期匿名成相对偏移，公司名映射成伪代码，模型无法触发对真实历史的记忆
- 时点安全：日线/5分钟/公告/新闻/基本面所有数据出口强制按模拟时点过滤
- 唯一撮合路径 + 数据全部预载内存，同样输入必然同样结果
- 指纹回放：每次 LLM 调用记录指纹，无需 API Key 即可逐位复现整个回测

实测：在沪深300 单月下跌 9.12% 的行情里，同一套提示词和工具配置跑 4 个模型、各自独立交易 21 个交易日：

Claude +1.45%（6 笔，最大回撤 0.76%）
Kimi +0.34%（全月只出手 2 次）
Qwen -1.64%（12 笔无一盈利）
DeepSeek -2.69%

同期沪深300 是 -9.12%，四个模型全部跑赢指数，但交易风格差异巨大。同样的市场、工具、提示词，模型的“性格”一目了然——这才是一个规范化考场该回答的问题。

另外每次回测自动沉淀全保真轨迹，可导出 SFT/RL 训练数据；5 年 A 股全市场数据集已发 HuggingFace。demo 不需要 API Key，pip 三行命令能跑。GitHub 搜 TraderHarness。

小样本实验，不构成投资建议。
